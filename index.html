没有一行代码去手动刷新 DOM，只要 effect 里读过的数据被改了，effect 就重新执行 → 生成新内容。这就是双向绑定的"向上"那一半。

⚠️ 新手最常踩的 4 个坑

1. 子组件里直接改 props： 会报警告且不生效，必须 emit('update:modelValue', 新值)。

2. v-model 绑的是 computed 但只给了 getter： 赋值会失败，computed 必须写成带 set 的对象形式。

3. select 第一项没写 value： iOS 下会出现选不中的问题，建议加 <option disabled value="">。

4. checkbox 忘了写 value： 一组 checkbox 会全部变成 true / false，而不是进数组。
